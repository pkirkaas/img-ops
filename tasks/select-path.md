# Task: Create a `select_path.py` widget

This widget is an enhanced/modified widget similar to the `tree_select` widget.

The select_path widget will be a pop-up, resizable dialog box that displays the expandable file system tree.

The tree nodes will be selectable folders, tree leaves will only be image files - non-image files will be hidden.

Only a single item (folder or file) can be selected in the tree.

The select_path widget will have an "OK" button which returns the selected path to the parent widget
